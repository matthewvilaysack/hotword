hotword

Say a phrase to your coding agent and a workflow of shell commands runs first. The report lands in the agent's context before it answers, so it starts from what is true instead of spending five tool calls finding out. 

$ 
hotword: repo-status
description: Branch, local changes, unpushed commits, and open PRs
steps[4]{name,status,exit,ms}:
  branch,ok,0,18
  unpushed,ok,0,22
  worktrees,ok,0,15
  open-prs,ok,0,640

branch:
  ## fix-timeout-kill...origin/fix-timeout-kill [ahead 2]
   M src/runner.rs

unpushed:
  a41c9de Kill the whole process group on timeout
  9be0d21 Skip a step whose cwd is missing

worktrees:
  ~/code/hotword           957bf85 [main]
  ~/code/hotword-timeout   a41c9de [fix-timeout-kill]

open-prs:
  #12  Kill the whole process group on timeout   fix-timeout-kill
cargo install --git https://github.com/matthewvilaysack/hotword
hotword install
Registers two hooks in your agent's settings. hotword uninstall takes them back out and leaves everything else alone.

Three moving parts

  1. A phrase you would type anyway. "repo status", "check the deploy", "where am I". Matching is a plain substring test, so hotword match "..." tells you exactly what fires.
  2. Steps that run in order, each on its own timeout. A step whose binary or directory is missing is skipped with the reason, not failed, so one file works across a team's mixed machines. A step past its timeout is killed along with anything it started.
  3. A compact report, capped to fit the agent's context limit. Summary table first, then each step's output, truncated with a hint for the full version. Never blocks the prompt; problems go to stderr and the exit code stays 0.

One TOML file per workflow

Made by the guided hotword add on a terminal, or by flags, or by hand.

name = "repo-status"
triggers = ["repo status", "where am i"]
on = ["session-start"]

[[steps]]
name = "branch"
run = "git status --short --branch | head -30"

[[steps]]
name = "unpushed"
run = "git log --branches --not --remotes --oneline"

[[steps]]
name = "open-prs"
run = "gh pr list --state open --limit 10"
requires = ["gh"]
timeout = 20

Commit it under .hotword/ in a repo and every teammate's agent learns the phrase on their next pull. Personal ones live in ~/.config/hotword/; a repo's file shadows a personal one of the same name.

Works with the agents you already run

Claude Code and Codex read the same hook shape, so one installer serves both. OpenCode loads a small plugin that shells out to the same subcommands.

Claude Codehotword install
Codexhotword install --agent codex, then trust it in /hooks
OpenCodecopy integrations/opencode/hotword.ts into your plugins folder
